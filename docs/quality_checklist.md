# Quality checklist — SHIP2666

Each item must be verified before the project can move toward COMPLETE.

## Completion rule
The word COMPLETE, a release tag, or a final-delivery claim must never be used while any visible placeholder, crude room, missing deck, unmodelled system, unfinished material, broken interaction or failed quality gate remains.

## Historical and spatial coverage
- [ ] Selected historical configuration documented and consistent (no mixed dates)
- [ ] Exterior silhouette and visible layout match archival references
- [ ] Principal dimensions and machinery arrangements have documented sources or labelled inferences
- [ ] Every deck and major structural region represented
- [ ] Space inventory contains 200+ individually identifiable spaces where evidence supports
- [ ] Every space has a real spatial role and coherent connections (no duplicate-box padding)
- [ ] Corridors, stairs, doors and deck connections work spatially (no dead-end impossible geometry)

## Geometry and visual quality
- [ ] No crude blockout primitive remains in any area presented as finished
- [ ] No placeholder geometry or untextured materials in the final ship
- [ ] Exterior steel, plating, decks, fittings, rigging, funnels, masts, boats production-quality
- [ ] Interior architecture, furniture, fabrics, fixtures, service areas detailed and historically plausible
- [ ] Close-up camera tests pass on representative assets throughout every deck and region
- [ ] No intersections, floating objects, incorrect scale, missing supports, broken topology
- [ ] Convincing under multiple cameras, lighting conditions and viewing distances

## Functionality
- [ ] Doors and movable fittings: correct pivots and collision
- [ ] Engine assemblies move with coherent mechanical kinematics
- [ ] Boilers, smoke, engine load, shafts, propellers respond to one ship state
- [ ] Steering and rudder operate coherently
- [ ] Ocean, hull interaction, wake and propeller wash work together visually
- [ ] Interactive systems tested and documented; decorative items not falsely described as functional

## Delivery and reproducibility
- [ ] 3D source project editable and buildable via documented instructions
- [ ] Ship explorable (not just a render gallery)
- [ ] Repository contains source, assets, evidence ledger, space/asset inventories, tests, README, final renders
- [ ] Render generation naming and automatic retention tested safely
- [ ] No credentials committed or exposed
- [ ] Final inspection renders cover complete ship, interiors, cutaways, machinery, close-ups
- [ ] All known defects resolved or explicitly disclosed
